# 10-зертханалық жұмыс. HTTP REST API арқылы АЖ компоненттерінің өзара әрекеттесуі

**Жүйе:** Жатақхана АЖ (`rooms` кестесі). Node.js + Express + SQLite (`database.sql`), тестілеу — Postman.

## Орындалу реті
1. Node.js нұсқасы 22.13 немесе жоғары болуы керек: `node -v`.
2. VS Code терминалында осы қапшыққа өтіп:
   ```
   npm install
   node server.js
   ```
   Алғашқы іске қосуда `database.sql` негізінде `dorm.db` базасы өзі жасалады.
   Терминалда `API сервері http://localhost:3000` шығады. Терминалды жаппаңыз.
3. Postman → Import → `DormAPI.postman_collection.json`, алты сұранысты ретімен Send басыңыз.
4. Базаны қайта нөлден жасау үшін `dorm.db` файлын өшіріп, серверді қайта қосыңыз.

## Endpoint-тер және күтілетін нәтиже
| № | Әдіс | Endpoint | Body | Нәтиже |
|---|---|---|---|---|
| 1 | GET | /api/rooms | — | 200, барлық бөлмелер |
| 2 | GET | /api/rooms/301 | — | 200, `{"room_number":301,"capacity":4,"occupied_beds":2}` |
| 3 | POST | /api/rooms | `{"room_number":306,"capacity":4,"occupied_beds":0}` | 201, бөлме қосылды |
| 4 | PUT | /api/rooms/301 | `{"capacity":4,"occupied_beds":3}` | 200, `Бөлме жаңартылды` |
| 5 | DELETE | /api/rooms/304 | — | 200, `Бөлме сәтті жойылды` |
| 6 | GET | /api/rooms/999 | — | 404, `Бөлме табылмады` |

Қосымша: `room_number`-сіз POST → 400; қайталанған нөмір → 409; `occupied_beds > capacity` → 400; QR-бұйрығы бар бөлмені (301) жою → 409.

## Қорытынды
Node.js және Express көмегімен жатақхана бөлмелерін басқаратын REST API әзірленді. API SQLite базасымен байланысады, CRUD операциялары жұмыс істейді, нәтижелер Postman арқылы тексерілді.

## Бақылау сұрақтарының жауаптары
1. **API** — бағдарламалар бір-бірімен деректер алмасатын интерфейс. Клиент серверге API арқылы сұраныс жіберіп, жауап алады.
2. **REST** ерекшеліктері: клиент пен сервер бөлек; сервер күйді сақтамайды (stateless); ресурстар URL арқылы анықталады; стандартты HTTP әдістері қолданылады; деректер көбіне JSON форматында жүреді.
3. **HTTP** — API-дің тасымалдау протоколы: клиент әдіс, URL және body жібереді, сервер статус-код пен JSON жауап қайтарады.
4. **CRUD:** Create (POST), Read (GET), Update (PUT), Delete (DELETE).
5. **GET** деректі оқиды, body болмайды, деректі өзгертпейді; **POST** body ішінде деректі жіберіп, жаңа ресурс жасайды.
6. **PUT** бар ресурсты жаңартады; **DELETE** ресурсты жояды.
7. **JSON** — жеңіл, барлық тілде оқылатын деректер форматы; клиент пен сервер арасында деректі бірдей құрылымда жеткізеді.
8. **Node.js** — серверде JavaScript орындайтын орта; **Express** — маршруттар мен сұраныстарды өңдеуді жеңілдететін веб-фреймворк.
9. **Postman:** New → HTTP Request, әдіс пен URL таңдалады, POST/PUT үшін Body → raw → JSON енгізіліп, Send басылады, жауап пен статус-код тексеріледі.

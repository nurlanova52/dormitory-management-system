# Студенттер жатақханасын басқару ақпараттық жүйесі
# Жобаның негізгі мақсаты — «Универ» ақпараттық жүйесінің әртүрлі процестерді біріктіретін ERP (Enterprise Resource Planning)  құрылымы аясында жатақхана процестерін автоматтандыруға арналған Транзакцияларды өңдеу модулін (TPS) әзірлеу. Жүйе дәстүрлі қағазбастылық пен ретсіз ақпараттық арналарды цифрлық форматқа ауыстырып, жатақхана әкімшілігі мен студенттер арасындағы оперативті басқару тиімділігін арттыруға бағытталған. 
## Жүйенің негізгі функциялары
- Студенттердің жатақханаға онлайн өтінім беруі
- Өтінімдерді қарастыру және орындарды бөлу
- Жатақхана тұрғындарының тізімін басқару
